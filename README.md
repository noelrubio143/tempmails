# AstrxyMail

Next.js temp mail app. Guide below is for running it on a VPS (Ubuntu 22.04 / 24.04).

## Requirements

- VPS with root access
- Domain with an **A record** pointing to the VPS IP
- Ports **80** and **443** open in the provider firewall
- Upstash Redis (free) so data is saved after restart

## Quick setup (one command)

Repo: https://github.com/noelrubio143/tempmails

```bash
# On the VPS (as root)
apt update && apt install -y git
git clone https://github.com/noelrubio143/tempmails.git
cd tempmails
sudo bash deploy/setup.sh yourdomain.com you@email.com

# Then fill in .env and restart
nano .env
pm2 restart astrxymail
```

If the repo is private, clone with a GitHub token:
`git clone https://noelrubio143:YOUR_TOKEN@github.com/noelrubio143/tempmails.git`

No GitHub? Upload the zip instead: `scp project.zip root@YOUR_VPS_IP:/root/`, then `unzip` it, `cd` into the folder and run the same `setup.sh` command.

## .env values

```
UPSTASH_REDIS_REST_URL=
UPSTASH_REDIS_REST_TOKEN=
ADMIN_SECRET_KEY=        # auto-generated by setup.sh
RESEND_API_KEY=
RESEND_FROM_EMAIL=
DISCORD_WEBHOOK_URL=
```

## Admin panel

- URL: `https://yourdomain.com/ops-vault`
- Login passcode = your `ADMIN_SECRET_KEY` from `.env`. To see it: `grep ADMIN_SECRET_KEY .env`
- Change it anytime: edit `.env`, then `pm2 restart astrxymail` (old sessions become invalid)
- Admin API calls use the same key in the `x-admin-key` header

## Useful commands

```bash
pm2 status                 # check if app is running
pm2 logs astrxymail        # view logs
pm2 restart astrxymail     # restart after editing .env
bash deploy/update.sh      # rebuild + restart after code changes
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d yourdomain.com   # retry SSL
```

## Manual setup (if you don't use setup.sh)

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs nginx git unzip
sudo npm i -g pnpm pm2

cp .env.example .env && nano .env
pnpm install --frozen-lockfile
pnpm build
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup
```

Then copy `deploy/nginx.conf` to `/etc/nginx/sites-available/astrxymail`, replace `__DOMAIN__` and `__PORT__` (3000), enable it, and run certbot.

## Notes

- Mail comes from external APIs (mail.tm / Guerrilla), so port 25 is not needed.
- On a 1GB RAM VPS, `setup.sh` adds 2GB swap so the build does not fail.
